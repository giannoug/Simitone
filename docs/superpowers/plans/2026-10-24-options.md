# Everyday Options Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provide Apply/Cancel for existing audio/display settings and retain the existing free-will control.

**Architecture:** Keep a detached seven-value draft in the options dialog. Add reliable, error-returning writes to the existing INI class, then reuse that method; no separate options service, reflection-based options framework, or custom recovery system.

**Tech Stack:** C#, existing MonoGame UI, GlobalSettings/IniConfig, HITVM; a package-free .NET console check.

**Spec:** [Approved design](../specs/2026-10-24-everyday-gameplay-design.md). Requires the preceding subsystem plans; see [release order](2026-10-24-everyday-gameplay.md).

## Global Constraints

- Provide Apply and Cancel; persist accepted settings across restart.
- Clearly label changes requiring restart.
- Do not expose unsupported settings.
- Do not reimplement the free-will algorithm.
- Reuse original game strings where available; add fallback text for new controls.
- Full translation coverage is not a release requirement.
- Windows gameplay validation is the release requirement.

## Review Focus

- Failed config writes must leave the previous readable file intact and expose the error (Task 1).
- Cancel/Escape must leave persisted and runtime settings unchanged (Task 2).
- Invalid width/height/volume must not partially apply (Task 2).
- Current-window resize must not overwrite pending restart-only display choices (Task 2).
- Duplicate modals, high DPI and minimum-size windows must keep controls reachable and block click-through (Task 2).

## Task 1: Fix config write errors at their source

**Interfaces:** Add `public bool IniConfig.TrySave(out string error)`; keep `public void Save()` as a compatibility wrapper calling TrySave and ignoring its result, preserving existing callers. Only the options Apply path opts into reporting failure. Do not change the INI schema or serialization rules.

Use `if (!condition) throw new Exception(message)` checks, not Debug.Assert (which can disappear in Release). Use fresh temporary folders and clean them in finally. Do not introduce xUnit, a runner package, a fake store or a second application service.
- [ ] In Program.cs construct a GlobalSettings on a temporary config path. Also check an invalid parent path returns false and legacy Save does not throw. Run `dotnet run --project Tests/Simitone.Checks/Simitone.Checks.csproj -c Release`; first require the missing-method failure, not a missing SDK/restore failure. - [ ] Implement TrySave in the existing INI class using the current serialization into a unique temporary file in the destination directory. This uses same-directory filesystem replacement, not a general journal or a promise of power-loss durability. ## Task 2: Small explicit options dialog

**Interfaces:** `UIOptionsAlert(GlobalSettings settings)` contains a private nested `OptionsDraft` record with seven values: four byte volumes, two int dimensions, and bool Windowed. The record needs no public API or separate file. The dialog's private `bool TryApply(out string error)` validates, copies the seven values into settings, calls TrySave, restores previous in-memory values on failure, and applies runtime audio only on success. `TS1GameScreen.ShowOptionsDialog()` maintains a single instance and clears its reference on close. Cancel/Escape closes without calling TryApply.

- [ ] Write O01: edit all four volumes, Cancel/Escape, verify config hash and live audio unchanged. O03: denied config write keeps the dialog open with error and restores runtime/in-memory values; retry succeeds. O04: Apply display changes, resize the old window, restart and verify accepted settings survive. O05: repeatedly open at 800×600 and 150% DPI; exactly one modal, reachable buttons and no click-through. O06: no-sound startup and existing 3D remain usable. Run the current build first to establish the missing/broken cases.
